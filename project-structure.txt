# Client Portal v2.0 - PBM Client Portal Project Structure

## PROJECT_OVERVIEW
```
Project Name: Client Portal v2.0
Type: PBM (Pharmacy Benefits Manager) Client Portal
Framework: Vue.js + TypeScript + Vuetify
Target Users: External (Consultants, Brokers, TPAs) + Internal (Staff)
Devices: Desktop, Laptop, Tablet, Mobile (Responsive)
```

## USER_TYPES_AND_PERMISSIONS
```
EXTERNAL_USERS:
- consultants, brokers, TPAs
- entity-scoped data access only
- standard UI with client-focused features
- cannot access other entities' data
- report explorer shows only their entity's accounts

INTERNAL_USERS:
- internal staff members
- access to all client data across entities
- enhanced UI with administrative features
- cross-entity report access
- additional administrative tools and bulk operations
```

## TECHNICAL_STACK
```
Frontend:
- Vue.js 3 with TypeScript
- Vue Router for navigation and route protection
- Vuex/Pinia for state management
- Vuetify components for UI framework

- PWA capabilities

Backend_API_Endpoints:
```


## MAIN_NAVIGATION_STRUCTURE

### 1. HOME_DASHBOARD
```
Route: /
Component: HomePage
Features:
- Summary widgets for pending items (high cost claims, prior auths, approvals)
- Quick access cards to main sections
- Report explorer for entity-level reporting
- Recent activity feed with real-time updates
- Mobile-optimized widget layouts
- Touch-friendly interface for mobile devices

Sub-routes:
- /dashboard (main dashboard view)
- /dashboard/widgets (widget configuration)
- /dashboard/reports (report explorer interface)

Report_Explorer_Features:
- Entity-level reporting dashboard
- Cross-account analytics for internal users
- Custom report generation
- Real-time data visualization
- Export capabilities
- Mobile-optimized report viewing
```

### 2. APPROVALS
```
Route: /approvals
Component: ApprovalsPage
Description: Single page displaying all reports pending user approvals
Features:
- Table view of all reports pending approvals
- Search functionality across all pending reports
- Filtering capabilities by report type, date, entity
- Export functionality for approval data
- Entity-scoped approval access
- Report approval actions directly from the table
- Mobile-optimized table view with touch interactions
```

### 3. REPORTS
```
Route: /reports
Component: ReportsPage
Description: Comprehensive PBM reporting system with organized report categories

Sub-pages (tabs):
- /reports/all (All reports - comprehensive list for all accounts under entity)
- /reports/approvals (Reports pending user approvals)
- /reports/ad-hoc (Custom reports created for accounts under entity)
- /reports/monthly-value (Monthly value reports for accounts under entity)
- /reports/quarterly-executive (Quarterly executive reports for accounts under entity)
- /reports/rebate (Rebate reports for accounts under entity)
- /reports/savings (Savings reports for accounts under entity)
- /reports/caa (CAA reports for accounts under entity)

Features:
- Tab-based navigation for organized report categories
- Entity-scoped report access for external users
- Cross-entity report access for internal users
- Report approval workflow management
- Custom ad-hoc report creation and management
- Export functionality (PDF, Excel, CSV)
- Search and filtering within report categories
```

### 11. SETTINGS
```
Route: /settings
Component: SettingsPage
Description: Account-specific settings management with user permissions and configuration

Page_Structure:
- Account selection modal (users first select account to manage)
- After selection, sub-pages (tabs) available:
  - /settings/company (Company information - company name, high-cost notifications)
  - /settings/users (User administration - permissions, activate/deactivate users)
  - /settings/caa-reporting (CAA Drug Cost Reporting Configuration)

Features:
- Account selection and management
- Company information management
- User permission management (read permissions for app pages)
- User activation/deactivation
- High-cost notification settings
- CAA reporting configuration
- CAA attestation management
- Entity-scoped settings management
```

```
Authentication:
- Role-based access control (RBAC) for external vs internal users

- Entity-level data isolation for external users

- PHI (Protected Health Information) handling
- Secure document storage
- Audit trails for all actions
- Data encryption at rest and in transit

- API rate limiting and security
```
